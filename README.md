# Hot Beans Web — Recruitment Website

A multi-page recruitment website developed in HTML, CSS, and JavaScript for my **Pearson BTEC National Information Technology (Unit 6: Website Development)** assignment, which achieved a **Distinction**.

## Overview
Built for a fictional London-based web development agency specialising in websites for schools, colleges, sixth forms, and universities, this site showcases the company's portfolio, trainee developer profiles, job specifications, and recommended learning resources while allowing prospective junior developers to apply online.

## Key Features
* **Consistent Multi-Page Navigation:** Uses a unified `<nav>` header across all six pages (`Home`, `About`, `Profiles`, `Job Specification`, `Courses`, and `Apply`) for intuitive access between pages.
* **Interactive JavaScript Application Form:** Features client-side validation (`validateForm()`) for mandatory fields, email formatting, and 11-digit UK phone numbers, alongside a form reset function (`setupForm()`).
* **Trainee Developer Profiles:** Showcases existing junior developers (Note that none of the employees mentioned are real people), their academic pathways, technical stacks, and project achievements.
* **Developer Career & Learning Hub:** Outlines full-stack, front-end, and back-end role requirements alongside links to Codecademy, freeCodeCamp, Udemy, W3Schools, and video tutorials.
* **Embedded Multimedia:** Incorporates promotional video content and visual assets to boost user engagement.

## Tech Stack
* **Structure:** HTML5
* **Styling:** CSS3
* **Client-Side Interactivity:** JavaScript

## Repository Contents
* `index.html` / `home.html` — Landing page featuring the company welcome message and embedded promotional video.
* `profile.html` — Company history, awards, and educational portfolio overview.
* `Employee Profile.html` — Profiles and backgrounds of existing trainee web developers.
* `JobSpec.html` — Role breakdowns, responsibilities, salary guides, and entry requirements.
* `Courses.html` — Recommended web development courses and video tutorials.
* `FORM.html` — Online job application form with JavaScript input validation.
* Media assets (`code.png`, `train.png`, `webdev.jpg`, `video-created-from-script.mp4`, and profile images) required across the site.
